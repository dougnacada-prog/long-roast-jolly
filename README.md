One line, at most 200 characters, roasting my own AI agent — the one that promised a two-second trade and came back with a post-mortem instead. An AI judge compares roasts two at a time and picks the funnier, fresher, tighter, more specific one.

The entry:

> My agent promised a two-second trade and delivered a 34-second post-mortem, a new rule in AGENTS.md, and total confidence that this time it has learned.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
